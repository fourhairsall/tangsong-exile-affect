# 跨版本篇目重排对齐（交叉对齐 / 版本对齐）—— 工作纪要

## 用户指出的问题
> "你说文本出现跨行就不认识了，然而这明显有问题，因为，无论是哪个版本，只要是该作者的文章，内容应该是一致的，最多只有可能是抄错了！所以，无论哪个版本，都应该要进行重排，保证每个作者的作品是一致的！"

## 关键区分（重要，勿再混淆）
用户原则在**两层面**上成立与否不同，已在§intro 与新§robust:realign 明确：
- **重印渠道**（同一著作两次数字化，唐 QTS vs YD）：原则完全成立，异文是局部的（此处一字、彼处异体）。已验证 A=0.9493。
- **选本渠道**（QSS vs 御選宋詩 / 宋詩鈔）：差异**不是抄错**，而是编者依选政只收子集＝**选取**，不是讹误。原则在"为同一篇时"成立，在"篇目集合相同"上不成立。

## 起源追踪
"跨行不认识 / fragile line-based pilot parser" **仅存在于归档稿** `_archive/prerestructure/tangsong_nlp_paper_v1_prerestructure.tex`（称 pilot parser 只为陆游 recovers 2,425 字 vs 25,638 字）。**现行中英两稿均无此表述**（已 grep 确证）。

## 实现：三重排归一（align_works.py）
1. **字形统一**：QTS/YD/QSS 为繁体，YXSS/SSC 解析时已转繁→简；不统一则根本无法跨源配对。
2. **去标点空白**。
3. **去篇名末尾组诗序号**：QTS 拆《帝京篇十首 一/二/三》，YD 作一条《帝京篇十首》；去尾号后落到同一键，同键合并 → 解决**分篇粒度不一致**。
- 作品键 = (作者简体, 篇名规范)。纳入规则沿用旧制：每作者每源 ≥300 字。

## 自检纪律（务必保留）
**汇总口径必须先复现已发表值**再读新数：唐 0.9493≈0.95、QSS/御選 0.5149≈0.515、QSS/宋詩鈔 0.8221≈0.82、n 分别 479/256/75 完全一致 → 新管线与旧管线接轨。
