## 三、推荐设计（可写入论文）

1. **主分析**：作者内配对差（same-author paired difference），纳入苏轼、白居易、刘禹锡、欧阳修、王禹偁、黄庭坚（限内集）6 人；秦观作边缘个案并报告宽 CI。
2. **系年替代**：不做逐诗校注式系年，而以**贬谪事件边界年**做粗粒度分期（起讫年见 exile_chronology.csv），接受 ±1 年误差；对边界年诗歌（如量移当年）作敏感性剔除。
3. **剂量代理**：贬所瘴疠等级 1–4（1 江淮近畿 / 2 长江中游 / 3 岭表近地 / 4 岭海南远），声明此为**文化地理等级**（B 级代理，非临床指标），据宋人地理观念与气候史常识构建。
4. **局限句（可直接引用）**：
   - "本研究语料（Chinese-Poetry 格式四库）不含诗级创作年代字段（实测覆盖率 0.0%），故贬谪期/非贬谪期切分依赖别集编年校注与年谱所定事件边界年，分期误差约 ±1 年。"
   - "柳宗元贬前存诗极少（<20 首）、韩愈与范仲淹贬谪期诗不足 30 首、辛弃疾诗存 154 首且系年薄弱、陆游无严格贬谪事件，四人排除于作者内对比；辛弃疾以词（编年笺注本）另立个案，陆游可作'退居'对照组而非贬谪组。"
   - "贬谪剂量以贬所瘴疠地理等级（1–4）为代理，属文化地理构念，其与真实健康/心理应激的关系仅为类比，不作生物学解释。"
5. **铁律执行**：exile_chronology.csv 中 evidence_grade=C 之条目（范仲淹 F2、辛弃疾 X1、陆游）均已显式标注，不得并入 A/B 级统计；黄庭坚仅内集部分按 A 级处理，外集系年结果须单独敏感性报告。

## 四、证据等级总注
- 系年事件本身：A=正史本传+编年校注/年谱明确一致；B=通行推断（量移、外任是否计贬）；C=定性存分歧或非贬谪。
- 各人贬期/非贬期诗数估计：基于语料实测总数 × 编年覆盖比例的**推断（D 级）**，动工前须逐首挂接核实；本备忘数字为设计测算下限，不是测量结果。
