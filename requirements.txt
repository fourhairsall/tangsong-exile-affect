# Traditional->simplified conversion. Two distributions expose the identical
# `opencc.OpenCC('t2s')` API, but their conversion dictionaries are NOT
# interchangeable at the precision reported in this paper:
#
#   opencc-python-reimplemented==0.1.7 -> Tang n=479 authors, A=0.9493
#   OpenCC==1.4.2                      -> Tang n=478 authors, A=0.9494
#
# Every number here was produced with the reimplementation, which reproduces
# cross_edition_points.json and Table tab:invariance exactly (Tang A=0.9493 at
# n=479; Song A=0.5149 at n=256). Substituting OpenCC 1.4.2 shifts the fourth
# decimal and drops one Tang author from the >=300-character inclusion set, so
# Table tab:tang and the realignment figures of tab:realign would not re-derive
# exactly. Prefer the pinned variant below; if only OpenCC is available, treat
# small discrepancies in the last reported digit as expected.
opencc-python-reimplemented==0.1.7
